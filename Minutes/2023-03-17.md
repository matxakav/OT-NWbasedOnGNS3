## Closed issues and decisions

- [Ziyao Wang](ziyao.wang@se19.qmul.ac.uk) proposed 2 defense approaches against Modbus attack, using ACL or intent. [Santiago Figueroa](sfigueroa@ceit.es) and [Ziyao Wang](ziyao.wang@se19.qmul.ac.uk) agreed to choose the ACL approach.
- [Ziyao Wang](ziyao.wang@se19.qmul.ac.uk) used `netconf` to connect vEOS to ONOS, so that ONOS can monitor the traffic through vEOS.
- [Ziyao Wang](ziyao.wang@se19.qmul.ac.uk) proposed a workflow for the ONOS APP to detect and then mitigate Modbus attack:

```
if [ packet frequency increases rapidly && these packet input from bottom interface ]; then
	start capture and inspect packet
	if [ packet has Modbus attack information ]; then
		generate openflow ACL
		deploy ACL into OVSes to filter packets
	fi
fi
```
