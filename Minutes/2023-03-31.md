## Closed issues and decisions

- [Ziyao Wang](ziyao.wang@se19.qmul.ac.uk) completed the implementation of DoS countermeasure on Modbus. He cached and counted all the Modbus packets with `WRITE_SINGLE_REGISTER` function code. If this kind of Modbus packets have frequency >= 10pkt/s, then a flow entry is deployed onto Open vSwitch to drop all packets that (1) have the same source MAC address with the attacker; (2) have destination IP address within the OpenPLCs' subnet `192.168.0.0/16`; and (3) have destination TCP port == 502.
